# JOWE

Desktop-приложение для расчета прямых и косвенных погрешностей измерений.

Что умеет:

- рассчитывать прямые погрешности по сериям измерений;
- рассчитывать косвенные погрешности по формуле через 4 метода;
- импортировать исходные данные из Excel;
- экспортировать отчет и графики в Excel;
- строить графики по измерениям и погрешностям;
- запускаться как обычное окно без `localhost`.

## Excel-формат

Шаблон можно создать прямо из приложения кнопкой `Сохранить шаблон Excel`.

Листы:

- `Setup`: формула в `B1`, имя результата в `B2`;
- `Variables`: `Variable`, `Instrumental Error`, `Unit`, затем измерения по строке.

## Установка зависимостей

```powershell
python -m pip install -r requirements.txt
```

## Запуск

```powershell
python main.py
```

## Сборка в EXE

```powershell
powershell -ExecutionPolicy Bypass -File .\build_exe.ps1
```
